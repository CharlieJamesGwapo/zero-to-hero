## The problem

A repository is public, but that does not by itself grant everyone permission to copy, modify, or redistribute its code.

## Concept

A license states the permissions and conditions for using a work. ZERO → HERO uses the [MIT license](https://github.com/CharlieJamesGwapo/zero-to-hero/blob/main/LICENSE). Read the actual license text before reusing code, content, images, icons, or fonts; those assets can have different owners and terms.

## Example

| Model       | Practical reading                                                            |
| ----------- | ---------------------------------------------------------------------------- |
| MIT         | Broad reuse permission; retain the copyright and license notice.             |
| Apache-2.0  | Broad reuse with notice requirements and an explicit patent license.         |
| GPL-3.0     | Copyleft terms apply when distributing a covered work.                       |
| Proprietary | Use depends on the owner's terms; source visibility alone is not permission. |

These are summaries, not substitutes for the full terms. Read the [MIT text](https://opensource.org/license/mit), [Apache-2.0 text](https://www.apache.org/licenses/LICENSE-2.0.html), and [GPL-3.0 text](https://www.gnu.org/licenses/gpl-3.0.en.html).

## How it works

A project's `LICENSE` file usually identifies its main software license. Dependencies each have their own licenses, and a repository may state different terms for documentation, trademarks, or supplied artwork. Before publishing a derivative project, record which assets you used and verify whether their terms are compatible with your distribution.

## Common mistakes

- Assuming “open source” means “no license” or “no conditions.”
- Copying an image found online because the code repository is MIT licensed.
- Removing required notices when distributing a modified version.

## Practice

Open the license files for ZERO → HERO and one dependency. Identify the copyright notice requirement in each. If you plan to reuse artwork or a font, find its separate usage terms rather than assuming the code license covers it.

## Checkpoint

Explain why a public repository with no license differs from an MIT-licensed repository. If the reuse terms are unclear, pause and ask the rights holder or obtain appropriate advice.
