# Task manager starter

`App.tsx` is a small React + TypeScript starting component. Put it in a React TypeScript project and render it as the root component. It supports adding, completing, filtering, and local persistence so you can focus next on editing, deletion, validation limits, and tests.

Tasks are saved only in this browser. Review the [project brief](../../src/lib/projects.ts) and verify keyboard use and corrupted storage before calling the project complete.
